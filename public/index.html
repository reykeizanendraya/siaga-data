Langkah singkat menggunakan SIAGA DATA

1. Klaim Token Akses

  1. Pada tab Pengguna, klik tombol Daftar / Klaim Token.
  2. Isi NIK (16 digit), No. WhatsApp, dan Alamat Email yang aktif.
  3. Klik Klaim Token. Token Akses (contoh: TKN-123456) akan muncul dan juga dikirim ke email Anda.
  4. Salin token tersebut. Token berlaku selama 3 jam sejak diklaim.

2. Masuk ke Aplikasi

  1. Masukkan NIK atau Nomor HP yang terdaftar.
  2. Tempelkan Token Akses yang sudah Anda klaim.
  3. Jika Anda sudah membuat password tambahan di menu Pengaturan, isi juga Password Akun.
  4. Klik Masuk untuk membuka Dashboard.

3. Menggunakan Fitur Utama

  • Dashboard – ringkasan dokumen, aktivitas, dan sisa waktu sesi.
  • Dokumen – lihat dan unggah dokumen kependudukan (KTP, KK, KIA, Akta).
  • SecureShare – bagikan dokumen secara aman melalui QR/tautan sementara.
  • Riwayat – pantau siapa dan kapan dokumen Anda diakses.
  • Notifikasi – informasi terbaru terkait akun dan dokumen.
  • Helpdesk – kirim pertanyaan atau laporan kendala ke petugas.
  • Pengaturan & Profil – atur password tambahan dan data diri.

1. Masuk sebagai Petugas

  1. Pilih tab Petugas Adminduk pada form login.
  2. Masukkan ID Tempat Kerja (contoh: ADM-001) dan Password.
  3. Klik Masuk sebagai Admin untuk membuka panel petugas.

2. Tugas Utama Petugas

  • Kelola dan perbarui data penduduk yang terdaftar.
  • Unggah dokumen kependudukan resmi ke akun penduduk.
  • Tanggapi tiket Helpdesk dari pengguna.
  • Pantau aktivitas akses untuk memastikan keamanan data.

Tips Keamanan

  • Jangan bagikan Token Akses atau password kepada siapa pun, termasuk yang mengaku petugas.
  • Selalu Keluar setelah selesai, terutama di perangkat umum.
  • Gunakan durasi berbagi dokumen sesingkat mungkin di SecureShare.
  • Aktifkan password tambahan di menu Pengaturan untuk perlindungan ekstra.

Pertanyaan Umum

  1. Token saya kedaluwarsa, apa yang harus dilakukan?
    Klik Daftar / Klaim Token lalu klaim ulang token baru dengan NIK yang sama.
  2. Email token tidak masuk?
    Periksa folder spam/promosi, atau pastikan alamat email yang diisi benar.
  3. Saya lupa password akun tambahan.
    Hubungi petugas melalui Helpdesk atau kantor Disdukcapil terdekat.
Butuh bantuan lebih lanjut? Setelah masuk, gunakan menu Helpdesk.
